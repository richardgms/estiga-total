## 📱 DICAS RÁPIDAS

### Para tirar boas fotos:
1. ☀️ Use boa iluminação (luz natural é melhor)
2. 📐 Mantenha o celular na horizontal (paisagem)
3. 🧹 Limpe e organize o ambiente antes
4. 😊 Pessoas devem parecer felizes e motivadas
5. 📸 Celular moderno funciona bem (não precisa câmera profissional)

### Dimensões ideais:
- Fotos grandes (hero, estrutura, modalidades): **1920x1080px**
- Fotos antes/depois: **600x800px** (vertical)
- Logos: **512x512px** ou maior
